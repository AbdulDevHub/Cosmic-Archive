# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, welcome people of every background and belief, keep criticism about the work, and leave out harassment, insults and personal attacks.

To report a problem, contact the maintainer privately through GitHub ([AbdulDevHub](https://github.com/AbdulDevHub)). Reports are kept confidential. The maintainer may remove comments, commits or contributors that break this code.
